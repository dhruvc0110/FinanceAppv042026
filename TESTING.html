Known limitations (NOT bugs)
  • Past-dated asset revaluations correct only the current total, not historical running balances.
  • F5/F18 pre-filled contribution/spending count setup-only months in the average — editable starting point.
  • F20 is a since-inception return vs a benchmark % you enter (no market-data time series). Benchmark + pill position are per-device (localStorage).
  • F24 bulk re-categorize doesn't block setting dr == cr (power-user action).
  • F12 rollover is computed (cumulative budget − actual), not a stored envelope balance.
  • The 'Pending' dashboard tile isn't in the reorder list, so it sorts to the end.
